# Code of conduct

Help keep issues, pull requests, and other project discussions welcoming and useful.

- Be respectful of different experience levels, backgrounds, and perspectives.
- Discuss code and behavior with concrete evidence. Give criticism without personal attacks.
- Do not harass, threaten, discriminate, post sexual content, or disclose another person's
  private information without permission.
- Do not spam discussions or repeatedly derail a resolved topic.

Maintainers may edit or remove content, lock discussions, or restrict participation when these
rules are violated. Responses should reflect the severity and repetition of the conduct.

Report problematic content through GitHub's reporting controls. For ordinary moderation
concerns, mention the repository maintainer in the affected discussion without repeating
private information. Security vulnerabilities have a separate [private reporting route](SECURITY.md).

These expectations apply to project-managed spaces and to representing the project publicly.
